快速开始

三步，在你的 Windows 上跑起来

克隆、配置、双击启动——桌面窗口与全部后端服务一键拉起。

Windows 10 / 11 Node.js 22+ pnpm 10+ Docker Desktop CopilotKit Intelligence 项目密钥 任意 OpenAI 兼容模型密钥

1克隆并构建

Windows 终端
# 获取代码并构建（需 Docker Desktop 已启动）
git clone https://github.com/xuboboo/zmuse.git
cd zmuse
pnpm install --frozen-lockfile
pnpm build:server & pnpm build:web
docker build -t openmuse-computer:local apps/computer
docker build -t openmuse-desktop:local  apps/desktop

2配置 .env

复制 .env.example 为 .env 并填入密钥。三个变量即可切换任意国内中转，无需改代码：

.env
# 国内中转即插即用（OpenAI 兼容协议）
AGENT_BACKEND=model
MODEL=openai/你的模型id
OPENAI_API_KEY=sk-xxx
OPENAI_BASE_URL=https://你的中转/v1

3双击 StartOpenMuse.cmd 一键启动

自动拉起 API、浏览器 worker 与中文界面；关窗缩到托盘，后台任务继续；子进程崩溃 3 秒自愈，托盘退出走优雅关停，不伤数据。

国内中转预设：AgentRouter → https://agentrouter.org/v1（GitHub 登录注册，开发者免费额度）、OpenRouter → https://openrouter.ai/api/v1（全球聚合，模型最全），或任意 OpenAI 兼容网关，填其 /v1 地址即可。
